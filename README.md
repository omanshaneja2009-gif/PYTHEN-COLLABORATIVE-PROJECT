# Student Energy Planner

A Python command-line project that helps students organize tasks and create a suggested study schedule.

## Features

- Add, view, and delete tasks
- Save tasks in a JSON file
- Prioritize tasks using days left, focus level, and difficulty
- Create study sessions and breaks before a chosen bedtime
- Show work that could not fit into the schedule

## How to Run

1. Install Python 3.
2. Open this project folder in VS Code.
3. Open the terminal and run:

   `python main.py`

## Technologies

- Python
- JSON for saving task data

## Limitations

The schedule is a suggestion based on the information entered by the user. The program does not calculate sleep cycles. It saves and displays exact deadline times, but currently uses days left when prioritizing tasks.
